# Google 저장소 버전

별도 Apps Script 프로젝트에 Code.gs 및 Index.html을 등록합니다. 기존 발송·백업 프로젝트와 운영 사이트는 별도로 유지합니다.

setupStorage를 실행하면 소유 계정에 별도 Google Sheets와 Drive 폴더를 생성합니다. 시트와 폴더는 비공개로 유지합니다. 멘토 명단과 프로그램은 관리자 화면에서 등록하며 기존 운영 명단은 자동으로 가져오지 않습니다.

관리자 인증에는 스크립트 속성 ADMIN_SALT와 ADMIN_HASH를 설정합니다. ADMIN_HASH는 SHA-256(ADMIN_SALT + 관리자 비밀번호)의 소문자 16진수입니다. 비밀번호 및 인증번호는 GitHub에 저장하지 않습니다.

웹앱을 소유자로 실행하며 모든 사용자가 접속 가능하도록 별도 배포한 후 실행 URL을 GitHub 저장소 변수 APPS_SCRIPT_URL에 등록합니다. GitHub Pages 배포 원본은 GitHub Actions로 선택합니다. 비공개 저장소의 Pages 사용 가능 여부는 GitHub 요금제에 따라 확인해야 합니다.

이 버전은 기본 목록·학교 이메일 인증·접수·관리자 등록·JSON 백업을 구현한 초기 버전입니다. 기존 사이트의 CARE 사전진단, CSV 병합, 단계별 상세 분석, 학과 담당 권한, 첨부파일, 복구와 재시도 자동화는 아직 이식되지 않았습니다. 실제 메일과 저장·동시접수 검증을 마친 뒤 운영에 사용합니다. 세션은 화면 메모리에 보관되며 새로고침 시 다시 로그인합니다. Apps Script 메일·실행시간 할당량이 적용됩니다.
